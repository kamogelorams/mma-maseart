# MMA MASEART Website

Static gallery website for MMA MASEART (Masidiba Susan Thobejane, Polokwane, Limpopo).

No build step needed. Files: `index.html`, `images/`, `vercel.json`.

## Deploy to GitHub
```
git init
git add .
git commit -m "MMA MASEART website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/mma-maseart.git
git push -u origin main
```

## Deploy to Vercel
1. Go to vercel.com and sign in with GitHub.
2. Click **Add New > Project** and import the `mma-maseart` repo.
3. Framework Preset: **Other**. Leave build command and output directory empty.
4. Click **Deploy**.

## Editing
- Artworks, sizes and prices: edit the `W` list in `index.html`.
- Contact number: search for `27820515249` and `082 051 5249`.
